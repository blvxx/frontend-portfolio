## Услуги

- Создание лендингов и небольших сайтов компаний.
- Редизайн и обновление структуры существующего сайта.
- Адаптация интерфейсов под смартфоны и планшеты.
- Исправление HTML, CSS и JavaScript.
- Доработка навигации, форм и интерактивных элементов.

## Технологии

- **HTML5** — семантическая структура.
- **CSS3** — адаптивные сетки, типографика и состояния интерфейса.
- **JavaScript** — интерактивные элементы и клиентская логика.
- **Responsive design** — поддержка мобильных и десктопных экранов.
- **Playwright** — проверка пользовательских сценариев и адаптивности.

## Локальный запуск

Сборщик и сервер разработки не требуются.

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/blvxx/web-development-portfolio.git
   ```

2. Открыть корневой `index.html` в браузере.
3. Для отдельного проекта открыть его `index.html` внутри каталога `projects/`.

## Автоматические проверки

GitHub Actions выполняет статические проверки и браузерные тесты.

Статические проверки охватывают:

- структуру `projects.json` и уникальность идентификаторов;
- наличие страниц и мобильного viewport у демо-проектов;
- соответствие ссылок на демо и исходный код реальным каталогам;
- существование локальных CSS, JavaScript и HTML-ссылок главной страницы;
- безопасные настройки iframe-превью и внешних ссылок.

Playwright проверяет адаптивность демо-сайтов, пользовательские сценарии, мобильную навигацию и компоненты SMM-страницы. Последние результаты доступны в [GitHub Actions](https://github.com/blvxx/web-development-portfolio/actions). На 24 ноября 2026 года последний workflow проверки завершился успешно: [посмотреть запуск](https://github.com/blvxx/web-development-portfolio/actions/runs/45381328752).

## Как оценить проекты

- Открыть страницы на десктопе и смартфоне.
