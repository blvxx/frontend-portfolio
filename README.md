# Web Development Portfolio | Freelance

Портфолио демонстрационных сайтов и практических работ по созданию и доработке веб-страниц для малого бизнеса.

**[Открыть опубликованный сайт](https://blvxx.github.io/frontend-portfolio/)** · **[Посмотреть исходный код](https://github.com/blvxx/frontend-portfolio)**

## Чем могу помочь

- Создать лендинг или небольшой сайт компании.
- Переработать структуру и визуальную подачу существующего сайта.
- Адаптировать страницы под смартфоны и планшеты.
- Исправить ошибки HTML / CSS / JavaScript.
- Добавить секции, формы, навигацию и небольшие интерактивные функции.

## Технологии

- **HTML5** — семантическая структура страниц.
- **CSS3** — адаптивные сетки, композиция, типографика и состояния интерфейса.
- **JavaScript** — интерактивные элементы и поведение интерфейса.
- **Responsive design** — адаптация под мобильные и десктопные экраны.

## Запуск локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/blvxx/frontend-portfolio.git
   ```
2. Откройте `index.html` в браузере.
3. Для просмотра отдельного проекта откройте соответствующий `index.html` внутри папки `projects/`.

Сборщик и сервер разработки не требуются: проекты реализованы как самостоятельные HTML/CSS/JavaScript-страницы.

## Как проверить работу

- Откройте главную страницу и все четыре концепта.
- Проверьте навигацию и интерактивные элементы.
- Измените ширину окна до мобильного размера.
- Проверьте, что содержимое не выходит за пределы экрана и действия интерфейса доступны с клавиатуры там, где это применимо.
