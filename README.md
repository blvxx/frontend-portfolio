Страница разделяет наличие формы, принятие тестовой отправки, генерацию сообщения и фактическое получение email. ## Локальный запуск

Сборщик и сервер разработки не требуются.

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/blvxx/Web-Development-Services.git
   ```

2. Открыть корневой `index.html` в браузере.
3. Для отдельного проекта открыть его `index.html` внутри каталога `projects/`.

## Автоматические проверки

GitHub Actions выполняет статические проверки и браузерные тесты.

Статические проверки охватывают:

- структуру `projects.json` и уникальность идентификаторов;
- наличие страниц и мобильного viewport у демо-проектов;
- соответствие ссылок на демо и исходный код реальным каталогам;
- существование локальных CSS, JavaScript и HTML-ссылок главной страницы;
- безопасные настройки iframe-превью и внешних ссылок.

Playwright проверяет адаптивность демо-сайтов, пользовательские сценарии, мобильную навигацию и компоненты SMM-страницы. Отдельная матрица проверяет пять ключевых страниц на ширинах 320, 375, 768 и 1440 px: title/description, viewport, один h1/main landmark, alt у изображений и отсутствие горизонтальной прокрутки. Последние результаты доступны в [GitHub Actions](https://github.com/blvxx/Web-Development-Services/actions). На 24 ноября 2026 года последний workflow проверки завершился успешно: [посмотреть запуск](https://github.com/blvxx/Web-Development-Services/actions/runs/45421786046).

## Проверки качества интерфейса

[Responsive & Accessibility Quality Gates](./docs/performance-accessibility-quality-gates.md) — перечень автоматических проверок и инструкция по ручному Lighthouse-аудиту. Lighthouse-оценки пока не публикуются: документ не выдаёт планируемые измерения за достигнутые результаты.

## Как оценить проекты

- Открыть страницы на десктопе и смартфоне.
- Проверить навигацию, формы и интерактивные элементы.
- Изменить ширину окна и проверить отсутствие горизонтальной прокрутки.
- Проверить клавиатурный фокус и доступность основных действий.
