# ДОМФОРМА — ремонт и отделка

Адаптивный концепт сайта локальной ремонтно-отделочной компании. Проект демонстрирует структуру коммерческого сайта услуг: позиционирование, направления работ, визуальную подачу, этапы взаимодействия, ответы на вопросы и форму запроса.

> **Статус:** самостоятельный демонстрационный концепт. Компания, интерьерные сцены и тексты вымышлены. Это не коммерческий клиентский проект, не реальный объект и не подтверждение фактически оказанных услуг. Форма работает только как демонстрация интерфейса и не отправляет данные.

## Что реализовано

- Первый экран с ясным предложением и несколькими точками входа.
- Блоки услуг, визуальные концепции помещений и последовательность этапов.
- FAQ на нативных элементах details/summary.
- Адаптивное мобильное меню.
- Форма запроса с HTML-валидацией и демонстрационным подтверждением.
- SEO-метаданные, семантическая разметка, видимый keyboard focus и поддержка prefers-reduced-motion.
- Интерьерные иллюстрации на CSS без внешних изображений, шрифтов и библиотек.

## Стек

HTML5 · CSS3 · Vanilla JavaScript · Responsive Design · Accessibility basics

## Локальный запуск

Сборщик и зависимости не нужны. Откройте index.html в браузере или запустите локальный статический сервер из корня репозитория:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/projects/domforma/.

## Чек-лист ручной проверки

- Проверить навигацию по якорям на desktop и mobile.
- Открыть мобильное меню, перейти по ссылке и убедиться, что меню закрывается.
- Отправить пустую форму и проверить встроенную валидацию браузера.
- Заполнить обязательные поля и проверить демонстрационное подтверждение.
- Проверить ширины 320, 375, 768 и 1440 px.
- Пройти страницу клавиатурой и проверить видимый focus.
- Проверить FAQ, отсутствие горизонтальной прокрутки и поведение при reduced motion.
